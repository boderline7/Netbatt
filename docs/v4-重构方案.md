# NetBatt v4 重构方案

> 状态：待确认，确认后再动代码。
> 基线：v3.1.27（versionCode 337），回退包 `NetBatt-v3.1.27.zip` 在仓库根。

## 1. 目标

一台常年放车里的 Android 手机（Magisk root），只做四件事：

1. **热点随车自动化**：车通电 → 自动开热点；熄火断电 → 自动关热点。
2. **空转保护**：热点开着但连续 15 分钟没有设备连上 → 自动关；下次通电再启动。
3. 可以手动选「常开不关」，也可以临时暂停几小时。
4. 充电阈值控制、无线 ADB、运行日志保持原有能力。

明确不做：

- 不做 USB 网络共享（自动共享 / 保留 ADB / 拔插逻辑 / USB 状态，**整段删除**）。
- 不再折腾「手机共享网络给车机」：车机 USB 口是 device 模式，方向相反；且车机
  `EthernetTracker` 白名单硬编码 `eth0_101|usb0`，新网卡不被接管。这条路已封死。

## 2. 取电方式：点烟器（已实测会断电）

| | 插车机 USB 口（旧设想） | 插点烟器（现在） |
|---|---|---|
| 手机角色 | USB host，反向给车机供电 | USB sink，被充电 |
| 车机参与 | 是，要枚举、要认网卡 | 否，完全不参与 |
| 「车在用」判据 | USB 总线上有非根集线器设备（易误判） | 充电器在线（干净） |

结论：检测逻辑从「猜」变成「看一个文件」，是本次重构最大的简化。

点烟器已确认会随车辆启停断电，因此不需要任何 ACC / 蓝牙兜底信号。

## 3. 检测信号

### 3.1 唯一主信号：充电器在线

```
/sys/class/power_supply/{usb,ac,dc,wireless}/online == 1
```

任一存在且为 1 → 有电。熄火断电后全部变 0。

### 3.2 辅助信号（OR，仅用于吸收电压抖动）

- 电池 `status == Charging`
- 电池 `current_now > 0`（正=充入）

熄火瞬间电压跌落可能让 `online` 短暂变 0 又回 1，靠下节的回滞吸收，不靠辅助信号救。

USB 相关的 `idVendor` / `dumpsys usb` 判据**全部删除**，不再需要。

## 4. 热点状态机

### 4.1 总开关

`AUTO_HS=1`（默认开）→ 模块按下面的规则自动开关热点。
`AUTO_HS=0` → 模块完全不碰热点，页面只提供手动开/关。

### 4.2 两种模式（总开关打开时生效）

| 模式 | 行为 | 对应需求 |
|---|---|---|
| `auto` | 有电开、断电关、15 分钟无设备关 | 默认，跟随车辆 |
| `always_on` | 有电就开，永不自动关 | 「手动选择不关闭」 |

### 4.3 开启回滞

只在 `auto` 模式生效，避免点火瞬间电压抖动导致反复开关：

- 有电信号**持续 ≥ 5 秒**才开（`ON_CONFIRM`）
- 断电信号**持续 ≥ 120 秒**才关（`OFF_CONFIRM`）

`always_on` 和「手动开/关」是明确指令，立即执行，不走回滞。

### 4.4 空转保护（新增）

`auto` 模式下，热点开着且**连续 15 分钟客户端数为 0** → 自动关热点。

客户端数怎么数：

```
iw dev <ap接口> station dump | grep -c '^Station'
```

取不到时兜底 `ip neigh show dev <ap接口>` 里 REACHABLE/STALE 的条数。

计时规则：

- 热点开 + 客户端 0 → 开始计时；一旦有客户端 → 计时清零。
- 达到 `IDLE_OFF_MIN`（默认 15，0=关闭该功能）→ 关热点，并置 `idle.hold`。
- `idle.hold` 存在期间**不再自动开**，直到电源断开（新一次通电）才清除。
  这样不会出现「关了又被状态机拉起来」的死循环。

`always_on` 模式不做空转保护——用户明确说了不关。

### 4.5 暂停

`PAUSE_UNTIL` 时间戳，优先级高于模式。网页提供 1 / 4 / 8 小时 + 恢复。

到点自动回到原模式，不需要额外定时任务，守护进程每轮比一下时间戳即可。

### 4.6 冷却与日志

- 热点被系统自己收回时，状态机会在下一轮重新拉起，**冷却 30 秒**，
  避免每 10 秒重建一次把系统 TetheringManager 打崩。
- 所有状态跳变只在真正变化时写日志，不刷屏。

## 5. 文件结构

```
netbatt/
├── module.prop              v4.0.0 / 400
├── post-fs-data.sh          不变（权限补齐）
├── service.sh               只做初始化 + 起守护
├── uninstall.sh             杀守护 + 停网页
├── bin/
│   ├── nb-core.sh           路径 / 配置 / 日志 / 工具
│   ├── nb-power.sh          信号检测 + 热点状态机 + 充电控制
│   ├── nb-adb.sh            无线 ADB（保留）
│   ├── nb-web.sh            网页服务 + 状态 JSON
│   └── nb-daemon.sh         常驻调度（替代 loop.sh + netbatt.sh）
├── system/                  不变（特权应用 + 权限白名单）
└── webroot/
    ├── index.html           重写
    └── cgi-bin/api.sh       精简 action
```

删除：`bin/nb-lib.sh`（91KB）、`bin/loop.sh`、`bin/netbatt.sh`。

守护方式从「每 5 秒 fork 四个 sh」改成「一个常驻进程 sleep 10 秒」，
减少 fork 开销和日志噪声。

## 6. 配置项

旧配置里的网段 / 固定入口 / DHCP 接管 / USB 类型相关键全部作废，
升级时只把充电阈值、日志设置、ADB 设置带过来（`CFG_V4` 标记，只做一次）。

| 键 | 默认 | 说明 |
|---|---|---|
| `AUTO_HS` | 1 | 热点随车自动化总开关 |
| `HOTSPOT_MODE` | `auto` | auto=跟车 / always_on=常开不关 |
| `PAUSE_UNTIL` | 0 | 暂停到期时间戳，0=未暂停 |
| `ON_CONFIRM` | 5 | 有电持续多少秒才开 |
| `OFF_CONFIRM` | 120 | 断电持续多少秒才关 |
| `IDLE_OFF_MIN` | 15 | 无设备连接多少分钟自动关，0=禁用 |
| `POLL_INT` | 10 | 守护轮询间隔（秒） |
| `PAUSE_CAP` / `RESUME_CAP` | 88 / 83 | 充电上限 / 恢复阈值 |
| `MAX_TEMP` | 45 | 过温暂停充电 |
| `CHG_MODE` / `CHG_SWITCH` / `SOC_PATH` 等 | 不变 | 充电通道，保持原样 |
| `ADB_TCP` / `ADB_PORT` / `ADB_BOOT` | 0 / 5555 / 1 | 无线 ADB，保留 |
| `LOG_MAX` / `LOG_ON` / `SAMPLE_INT` | 不变 | 日志 |

已删除的键（升级时丢弃）：`PREFIX`、`POOL_START`、`POOL_END`、`DNS1`、`DNS2`、
`FIXIP`、`FWDPORT`、`USB_NET`、`USB_NATIVE`、`USB_KEEP_ADB`、`USB_DHCP_TAKEOVER`、
`KEEP_WIFI`、`KEEP_USB`、`BOOT_WIFI`、`BOOT_USB`、`ADB_KEEP`。

## 7. 网页面板

只留五块：

1. **状态条**：热点开/关、当前模式、车用信号、自动化是否生效。
2. **热点随车自动化**：总开关 + 模式（自动 / 常开）+ 暂停（1/4/8 小时 / 恢复）+ 手动开/关。
3. **电量 / 充电阈值**：进度条 + 上下限 + 充电控制开关。
4. **无线 ADB**：开关 + 端口 + 开机恢复。
5. **运行日志**：最近 200 行、刷新、清空、导出到 Download、记录开关。

页脚显示版本号 + 构建号（用于判断 WebView 缓存是不是旧页面）。

去掉：USB 全部、网段设置、设备列表、端口转发、USB 类型选择、所有探测按钮。

## 8. 砍掉的功能及原因

| 功能 | 原因 |
|---|---|
| USB 网络共享（全部） | 本次需求删除；且对车机方向相反、框架白名单不认 |
| 自建 dnsmasq / DHCP 接管 | 与系统 tethering 抢 67 端口，v3.1.7 已确认是热点崩溃根因 |
| 网段设置（192.168.8.x） | 地址由系统 tethering 分配，模块不参与即无冲突 |
| 固定入口 10.1.2.3 + /32 旁挂 | 依赖模块自己配的网段，网段交出去后失去意义 |
| 端口转发（NETBATT_FIX） | 同上，车机场景已不需要 |
| 设备列表 / 租约解析 | 依赖模块自己的 dnsmasq |
| USB 类型选择（rndis/ncm/ecm） | 不再做 USB 共享 |
| 探测 / 诊断按钮 | v3.1.27 已删除，改为电脑 adb 排障 |
| configfs 直写 / usb-gadget.sh | 本机 mtu3 驱动在 UDC 解绑时会死机 |

## 9. 验证清单

装好后按顺序做，结果会进日志（网页「导出」即可拿到整份）：

1. **点火**：等 10 秒，热点自己起来；日志出现「热点: 开启（车用…）」。
2. **熄火**：等 2 分钟，热点自己关；日志出现「热点: 关闭（断电…）」。
3. **抖动**：点火瞬间不应出现「开-关-开」反复（看日志里开关条数）。
4. **空转**：开着热点不连任何设备，15 分钟后应自动关；再拔插一次电源应重新开。
5. **常开**：切到「常开」后拔电源，热点不应被关（手机还有电的前提下）。
6. **暂停**：点「暂停 1 小时」，热点应立即关，且到点前不会被拉起。

排障命令（手机 root shell 里跑，熄火 / 点火各跑一次）：

```sh
for p in usb ac dc wireless; do f=/sys/class/power_supply/$p/online; [ -f "$f" ] && echo "$p=$(cat $f)"; done
echo "cap=$(cat /sys/class/power_supply/battery/capacity) status=$(cat /sys/class/power_supply/battery/status) cur=$(cat /sys/class/power_supply/battery/current_now)"
ip -o -4 addr show | grep -Ei 'wlan2|ap0|swlan0|softap0'
iw dev 2>/dev/null | awk '/Interface/{n=$2} /type AP/{print "AP="n}'
```

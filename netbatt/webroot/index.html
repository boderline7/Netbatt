USB 共享（网桥）

状态--
地址分配--
USB 链路--
上行网络--
默认交给系统共享（TetheringManager），网段由系统决定（实测 192.168.16.x），地址分配与 NAT 也由系统负责，兼容性最好；对端拿不到地址时才回退到模块自建，此时固定 192.168.8 段。热点那边的设备可以直接访问对端设备的端口。热点开着时插新设备，模块会短暂让出 DHCP 端口把地址发下去再恢复；每次 USB 接入只接管一次，成功以 DHCP ACK 为准。USB 链路与上行网络分开显示：单 Wi-Fi 通道机型开热点时上行会断，那是正常现象，不代表 USB 侧失败。

USB 网络类型

当前生效--
对端完全看不到网卡时换这里，跟 DHCP 无关。RNDIS 兼容性最好（随身 WiFi 基本都是它），NCM 要求对端有 cdc_ncm 驱动，ECM 要求本机存在该 function。注意：部分 ROM（vivo 就是）不接受直接改 sys.usb.config，会建出 function 目录却不链接进配置，内核不建网卡，此时这四项切了也没用，必须走系统共享。上方共享方式显示「系统共享」才说明网卡真的建出来了。
